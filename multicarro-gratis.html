Política de Privacidade

Multi-carro Grátis — última atualização: agosto de 2026

O Multi-carro Grátis é um app pra controlar abastecimento, manutenção e documentos de veículos. Esta política explica quais dados o app usa e como.

Dados guardados no seu celular

Por padrão, tudo que você cadastra — abastecimentos, manutenções, documentos, dados do veículo (nome, apelido, placa, renavam, cor, km) e foto do carro — fica salvo apenas no seu aparelho. O app não exige cadastro, login ou conta de usuário.

Sincronização com a família (recurso opcional)

Se você ativar "Sincronizar com a família", os dados do veículo (abastecimento, manutenção, documentos, nome, placa etc. — exceto a foto, que continua só local) passam a ser enviados e guardados num banco de dados na nuvem (Supabase), pra que outras pessoas com o mesmo código de acesso possam ver e editar as mesmas informações.

  • Esse recurso é desligado por padrão — só é ativado se você escolher.
  • Qualquer pessoa que tiver o código de sincronização consegue ver e editar os dados daquele grupo. Não compartilhe o código com quem você não confia.
  • Você pode desativar a sincronização a qualquer momento — os dados continuam salvos no seu celular, só param de ser compartilhados.
  • Para pedir a remoção completa dos dados sincronizados na nuvem, entre em contato pelo e-mail no final desta página.

Anúncios

O app exibe anúncios fornecidos pelo Google AdMob. Para exibir anúncios relevantes, o AdMob pode coletar automaticamente:

  • Identificador de publicidade do dispositivo (Advertising ID)
  • Informações técnicas do aparelho (modelo, sistema operacional, idioma, região)
  • Dados de interação com os anúncios (impressões, cliques)

Essa coleta é feita e processada pelo Google, conforme a Política de Privacidade do Google e a política de dados do AdMob.

Compartilhamento de dados

Não vendemos dados a terceiros. Os únicos processamentos por terceiros são o AdMob (anúncios, descrito acima) e o Supabase (banco de dados usado só quando você ativa a sincronização com a família).

Permissões

O app pede acesso à galeria de fotos apenas quando você escolhe trocar a foto de um veículo. Nenhuma outra permissão sensível (localização, contatos, câmera direta) é solicitada.

Crianças

Este app não é direcionado especificamente a crianças menores de 13 anos e não coleta intencionalmente dados de menores.
