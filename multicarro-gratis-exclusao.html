Exclusão de Dados

Multi-carro Grátis, desenvolvido por Guto Tanner — última atualização: agosto de 2026

Dados guardados só no seu celular

Abastecimentos, manutenções, documentos e fotos ficam salvos apenas no seu aparelho. Você pode apagar cada registro a qualquer momento direto no app (toque e segure no item → Remover), ou apagar tudo de uma vez desinstalando o app.

Dados enviados pela sincronização com a família (opcional)

Se você ativou "Sincronizar com a família", os dados do(s) veículo(s) daquele código (abastecimento, manutenção, documentos, nome, placa, renavam, cor — exceto foto, que nunca sai do celular) ficam guardados num banco de dados na nuvem, associados ao código de sincronização.

Exclusão automática após 90 dias

Não é preciso pedir nada: qualquer código de sincronização que fique 90 dias seguidos sem nenhuma atualização (nenhum abastecimento, manutenção ou documento novo registrado por ninguém que tenha o código) é apagado automaticamente e por completo do banco de dados na nuvem.

Se você quiser que a exclusão aconteça mais rápido, é só parar de usar aquele código — os dados dele somem sozinhos assim que completar 90 dias de inatividade.

O que é excluído e o que permanece

  • Excluído após 90 dias de inatividade: todo o registro do banco de dados na nuvem associado ao código (abastecimentos, manutenções, documentos, dados do veículo).
  • Não afetado: os dados que já estão salvos localmente em cada celular que usou aquele código continuam lá, já que ficam armazenados no aparelho, não na nuvem. Pra apagá-los, é preciso fazer isso em cada celular (ver seção acima) ou desinstalar o app.
